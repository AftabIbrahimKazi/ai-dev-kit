# UI Standards — Export (reference)

Read when: the task covers excel, pdf and word. The everyday rules are in `ui-standards/export.md`.

## Excel

- **UI-EXP-14** Each data sheet: rows 1 to 5 the header block (logo and title, subtitle, date, filters, sort and count, generated by and classification), row 6 empty, row 7 the column header (bold, light grey fill, AutoFilter), data from row 8, frozen panes below the header row, columns auto-sized to at most 50 characters, and a final "Total" row with `SUBTOTAL(109, …)` for summable columns. No merged cells in the data area. Amounts and dates are typed values with display formats, never text; totals are formulas.
- **UI-EXP-15** Tab names are Title Case nouns ("Laptops", "In repair"), at most 31 characters, unique, without `[ ] : * ? / \`. Order: optional "Summary", data sheets, then "Report info" (title, subtitle, date, filters, sort, columns, records, generated by and at, classification, product). Beyond Excel's 1,048,576 rows split into numbered sheets ("Laptops 1", "Laptops 2") and say so in "Report info".
- **UI-EXP-16** Set A4, landscape above 6 columns, fit to page width, header row repeated on every printed page, footer "Page &P of &N".
- **UI-EXP-17** CSV holds only the header row and data (no header block, no totals), UTF-8 with BOM, comma separators, `"` quoting, dates in the human format.


## PDF and Word

- **UI-EXP-18** A4 with 15 mm margins (Word: 20 mm top), portrait for single records and lists up to 6 columns, landscape for 7 to 10, the product font embedded (Word: that font with a system fallback; embed a font that covers every supported script). Lists over 10 columns are not exported to PDF or Word; the dialog says "Use Excel for more than 10 columns."
- **UI-EXP-19** Page 1 shows the full header block; later pages a compact header (small logo and "<Title> (continued)").
- **UI-EXP-20** Table header rows repeat on every page and rows never split across pages. Numbers are right-aligned in tabular figures. Long text wraps, never truncates. Totals sit on the last page followed by "— End of report · N records —".
- **UI-EXP-21** A single-record document uses the same header and footer, the document type as title ("Asset sheet", "Handover form"), the record identifier as subtitle, the date below, then sections as on the detail page (heading and key–value grid), then photos, related tables and, for forms, signature lines with name and role.
- **UI-EXP-22** PDFs are tagged: title metadata, document language, heading and table-header tags, logo alt text. Word files use built-in Heading styles, real tables with a header row, and alt text for images.
