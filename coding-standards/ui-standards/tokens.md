# UI Standards — Design Tokens

Read when: you need any colour, size, spacing, radius, font, motion or layer value, or you set up or change a token pipeline. A project's own design source (`design.md`, Figma, tokens) wins on the values below; they are the defaults when none exists.

## Pipeline

- **UI-TOK-01** Every token value is defined once, in a token source (W3C DTCG JSON), with a light file and a dark file. A document of the tokens matches the source. Never define a value twice.
- **UI-TOK-02** Generated files (CSS variables, Tailwind preset, Flutter, React Native, resolved JSON) are produced only by the build script. Never edit them by hand; projects copy or sync them unchanged.
- **UI-TOK-03** Every colour token exists in both the light and the dark file under the same name; the build fails otherwise.
- **UI-TOK-04** Components use semantic tokens only (`color.text.secondary`, `space.4`, `radius.md`). The Tailwind preset replaces Tailwind's default palette so palette classes do not exist. Flutter uses the generated colour class, React Native the generated colour objects. A token name maps to a CSS variable by replacing dots with dashes (`color.bg.page` becomes `var(--color-bg-page)`).
- **UI-TOK-05** A token change is a merge request that edits the source and the document, regenerates the outputs, passes the contrast checks in both modes, and bumps the version (patch: value fix; minor: new token; major: rename or removal). A renamed or removed token keeps an alias for one minor version. CI runs the build in check mode on token changes.
- **UI-TOK-06** CI verifies text pairs at 4.5:1, interface component and chart pairs at 3:1, and the focus ring at 3:1, in both modes, from the resolved JSON.
- **UI-TOK-07** Bundle the font with every app (self-hosted `woff2` with `font-display: swap` on the web; bundled files in Flutter and React Native), weights 400, 500, 600 and 700 only. No third-party font CDN.

## Default values

- **UI-TOK-10** Neutral colours (light / dark): page `#F5F6F8` / `#0B0F17` (Cool `#F1F5FB` / `#0A1020`, Warm `#FAF8F4` / `#100E0B`); surface `#FFFFFF` / `#111827`; raised `#FFFFFF` / `#1F2937`; subtle border `#E5E7EB` / `#1F2937`; field border `#8A919C` / `#6B7280`; text primary `#111827` / `#F3F4F6`; secondary `#4B5563` / `#C9CED6`; muted `#6B7280` / `#9CA3AF`; overlay `rgba(17,24,39,0.45)` / `rgba(0,0,0,0.6)`; menu-search highlight `#FEF08A` / `#854D0E`.
- **UI-TOK-11** Fixed-meaning colours (bg / text, light then dark): success `#DCFCE7` / `#14532D`, dark `#14532D` / `#BBF7D0`; warning `#FEF3C7` / `#78350F`, dark `#78350F` / `#FDE68A`; danger `#FEE2E2` / `#991B1B`, dark `#7F1D1D` / `#FECACA`; info `#DBEAFE` / `#1E3A8A`, dark `#1E3A8A` / `#BFDBFE`; danger text `#B91C1C` / `#FCA5A5`; solid danger button `#B91C1C` with `#FFFFFF` / `#FCA5A5` with `#111827`; alert badge `#DC2626` with white (dark `#EF4444`); image viewer `rgba(0,0,0,0.92)` with `#F9FAFB`; toast = inverted text-primary and surface; environment badge `#FDE68A` / `#78350F` (dark `#FCD34D` / `#1F2937`).
- **UI-TOK-12** Generated colours per theme: primary fitted for 4.5:1 labels and links; hover is primary lightness −0.06 (light) or +0.06 (dark), pressed ±0.11; on-primary the label colour; focus ring = primary, 2 px with 2 px offset; header and sidebar background by style; nav text, hover, active pill, indicator and border by the generator; table row hover and selected row (primary tint). Menu presets (light / dark): Default `#FFFFFF` / `#111827`, Dark `#111827` / `#030712`, Navy `#1E2A4A` / `#121A33`, Brand = primary hue at OKLCH L 0.30 C 0.06 / L 0.22 C 0.05.
- **UI-TOK-13** Type: sans stack `"Inter", system-ui, -apple-system, "Segoe UI", sans-serif` (or the brand font), mono `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`. Sizes: caption 12 px / 16, body-sm 14 / 20, body 16 / 24, heading-sm 16 / 24 weight 600, heading 20 / 28 weight 600, title 24 / 32 weight 600. Weights 400, 500, 600, 700.
- **UI-TOK-14** Spacing on a 4/8 pt grid: `space.1`…`space.12` = 4, 8, 12, 16, 20, 24, 32, 40, 48 px (`space.1`, `.2`, `.3`, `.4`, `.5`, `.6`, `.8`, `.10`, `.12`). Radius: sm 6, md 8, lg 10, xl 16, full 999 px.
- **UI-TOK-15** Elevation: overlay shadow `0 8px 24px rgba(17,24,39,0.12)` in light, none in dark (use the raised surface and a border). Sizes: header 64 / 56 px, sidebar 260 / 72 px, control xs 28, sm 32, md 36, touch 44 px, button min width 64 (sm) and 80 (md), touch target 44 px minimum under `pointer: coarse`, icons 16, 18, 20 px on a 24 px grid with 2 px stroke.
- **UI-TOK-16** Motion: fast 150 ms (chevrons, small state changes), base 250 ms (drawer and sheet enter), exit 200 ms, slow 400 ms (rare). Easing standard `cubic-bezier(0.2, 0, 0, 1)`, decelerate `cubic-bezier(0, 0, 0, 1)` for enter, accelerate `cubic-bezier(0.3, 0, 1, 1)` for exit. Under `prefers-reduced-motion: reduce` durations become 0 ms except opacity fades of 100 ms or less.
- **UI-TOK-17** Layers: sidebar 150, header 200, dropdown 300, drawer 400 (navigation drawer, bottom sheets, theme panel), dialog 500, toast 600, skip link 1000. A dropdown, select panel or popover opened from inside a drawer or dialog uses 550 (above dialog, below toast) and renders where the container's overflow and stacking context cannot clip or cover it (the dialog's top layer, or a portal at the end of `<body>`).
- **UI-TOK-18** Chart series 1 to 8 (light / dark): `#3D6FB6` / `#7FA7E0`, `#C46A2F` / `#E0A06E`, `#2E8072` / `#6FBFAF`, `#7A5FA8` / `#AE97D6`, `#B5547A` / `#DE8FAE`, `#8A7A2E` / `#CDBE6A`, `#5A8A3A` / `#9CC27A`, `#6B7280` / `#A3AAB6`. Gridlines `#EEF0F3` / `#1F2937`; tooltip `#111827` with `#F9FAFB` (dark `#F3F4F6` with `#111827`); future periods use the hover tint at 70%.
- **UI-TOK-19** Logo assets per product: full, mark, and single-colour variants for light and dark. The mark falls back to the first letter in a 32 px rounded square.
