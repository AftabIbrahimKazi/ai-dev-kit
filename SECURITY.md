# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting: open the repository's **Security** tab, choose **Report a vulnerability**, and describe what you found, how to reproduce it and which version or commit it affects.

You can expect an acknowledgement within a few days. Confirmed issues are fixed on `main` and noted in the changelog.

## Scope

The kit installs skills, hooks and standards into your own projects and runs local scripts. Reports about those scripts, the installer, or hooks that read or write files outside the project are in scope. Findings in third-party services the add-ons call are not.
